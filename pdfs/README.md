# PDF inputs

Place PDFs here before running the **Convert PDFs to Markdown** GitHub Actions workflow.

PDFs added to this folder are committed to the repository's Git history. If the repository is public, they are visible to everyone. Use only documents you are authorized to make public, or use the local converter / a private input repository.

The workflow uploads the converted Markdown files to a GitHub Release; it does not upload PDFs as release assets. Release visibility follows the repository's visibility.
